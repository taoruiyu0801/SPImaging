# Synthetic Simple3D checkpoint recipe

`simple3d_synthetic.pt` is generated by
`scripts/generate_synthetic_demo.py`. The script performs the following fixed
CPU recipe:

1. Generate all four analytic CC0 samples with seeds `2026082301` through
   `2026082304`.
2. Sum each 1024-bin photon cube in groups of 64, producing 16 temporal bins.
3. Use every second spatial pixel during training, producing a centered
   deterministic `16 x 32 x 32` training volume from each sample.
4. Apply `log1p` and per-sample maximum normalization.
5. Train Simple3D with 2 base channels, an AdamW learning rate of `0.003`,
   weight decay `1e-5`, depth-target sigma `0.75`, 8 epochs, batch size 1, and
   fixed sample order.
6. Save model weights and primitive metadata only. The checkpoint is verified
   with `torch.load(..., weights_only=True)`.

The authoritative parameters, framework version, input hashes, metrics, output
size, and output SHA-256 are in `../manifest.json`. This tiny checkpoint exists
to exercise prediction/evaluation and GUI visualization; it is not trained for
or represented as accurate on real measurements.
